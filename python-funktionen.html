def — Funktionen in Python
mit Parametern und return

Eine Funktion ist wie eine Maschine: Sie nimmt Werte entgegen (Parameter), verarbeitet sie und gibt ein Resultat zurück (return). Auf dieser Seite probieren Sie das interaktiv aus — und lernen die häufigste Stolperfalle kennen.

01 / AUFBAUWie ist eine Funktion aufgebaut?

Jede Funktion in Python besteht aus denselben vier Bausteinen. Fahren Sie mit der Maus über die farbigen Teile.

def addiere(a, b):
    return a + b
def

Das Schlüsselwort, mit dem jede Funktionsdefinition beginnt. Es bedeutet: «Hier wird eine neue Funktion definiert.»

addiere

Der Funktionsname. Sie wählen ihn selbst — er sollte beschreiben, was die Funktion tut.

(a, b)

Die Parameter: Platzhalter für die Werte, die beim Aufruf übergeben werden. Sie verhalten sich wie Variablen innerhalb der Funktion.

return a + b

Gibt das Resultat zurück an die Stelle, an der die Funktion aufgerufen wurde — und beendet die Funktion sofort.

Wichtig: Die Definition allein führt noch nichts aus. Erst der Aufruf — z. B. addiere(3, 4) — startet die Funktion. Die Werte 3 und 4 heissen dann Argumente und landen in den Parametern a und b.

04 / ACHTUNG, STOLPERFALLEreturn zeigt nichts an!

Der häufigste Anfängerfehler: Man ruft eine Funktion auf, das Programm läuft — aber auf dem Bildschirm erscheint nichts. Warum? Probieren Sie beide Varianten aus.

✗ Variante A — ohne print
def quadrat(x):
    return x * x

quadrat(5)
Konsole
— noch nicht ausgeführt —
✓ Variante B — mit print
def quadrat(x):
    return x * x

print(quadrat(5))
Konsole
— noch nicht ausgeführt —
⚠️

Merksatz: return gibt den Wert nur an das Programm zurück — nicht an Sie! In Variante A wird 25 zwar berechnet, aber niemand fängt den Wert auf, und er verschwindet. Erst print() bringt den Wert auf den Bildschirm. Wer das Resultat einer Funktion sehen will, schreibt also print(quadrat(5)) oder speichert es zuerst: r = quadrat(5) und dann print(r).

Und umgekehrt? Eine Funktion, die nur print() benutzt und kein return hat, gibt automatisch None («nichts») zurück. Mit ihrem «Resultat» kann man dann nicht weiterrechnen: 
def quadrat_print(x):
    print(x * x)        # zeigt nur an, gibt nichts zurück

a = quadrat_print(5)    # Konsole: 25
print(a + 1)            # 💥 TypeError: None + 1 geht nicht!

05 / GEGENÜBERSTELLUNGprint() vs. return — wer macht was?

Die beiden werden oft verwechselt, machen aber völlig verschiedene Dinge.

print() return
Zweck Anzeigen: schreibt einen Wert in die Konsole, damit ein Mensch ihn sieht. Zurückgeben: liefert einen Wert an das Programm, damit es damit weiterrechnen kann.
Wer «sieht» den Wert? Sie — auf dem Bildschirm. Das Programm — der Wert kann in einer Variablen gespeichert werden.
Weiterrechnen möglich? Nein. Was gedruckt ist, ist «weg» — nur sichtbar, nicht speicherbar. Ja: r = addiere(3, 4), danach r * 2 usw.
Beendet die Funktion? Nein — der Code läuft danach weiter. Ja — sofort. Code nach return wird nie ausgeführt.
Typische Verwendung Resultate ausgeben, Zwischenwerte beim Fehlersuchen anzeigen. In fast jeder «Rechen-Funktion» — die Anzeige übernimmt dann der Aufrufer mit print().
