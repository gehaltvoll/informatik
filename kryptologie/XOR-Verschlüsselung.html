XOR-Verschlüsselung

Computer verschlüsseln nicht Buchstaben, sondern Bits. Die einfachste Bit-Operation dafür heisst XOR. Hier lernst du Schritt für Schritt, wie aus einem Buchstaben eine Folge von Nullen und Einsen wird und wie XOR daraus einen Geheimtext macht – und wieder zurück.

Schritt 1 · Buchstaben → Bits

Jeder Buchstabe ist eine Zahl

Im Computer hat jedes Zeichen eine Nummer. Diese Zuordnung heisst ASCII-Tabelle: A ist 65, B ist 66 und so weiter, das Leerzeichen ist 32. Gespeichert wird diese Zahl im Binärsystem mit 8 Bits, also einem Byte.

Jedes Bit hat einen Stellenwert: 128, 64, 32, 16, 8, 4, 2, 1. Die Zahl ist die Summe der Stellenwerte, an denen eine 1 steht.

H→72→01001000

Tipp: Klicke auf ein Bit, um es umzulegen. Du siehst sofort, welcher Buchstabe daraus wird.

Mehr dazu findest du im ASCII-Binär-Wandler.

Schritt 2 · Die XOR-Regel

XOR: «entweder – oder»

XOR steht für exclusive or, auf Deutsch «exklusives Oder». Es vergleicht zwei Bits und liefert 1, wenn sie verschieden sind, und 0, wenn sie gleich sind. Das Zeichen dafür ist ⊕, in Python ^.

Probiere es aus – klicke auf die Bits
⊕ = 0

Bit ABit BA ⊕ B
Zwei Arten, sich XOR zu merken

Ungleich ergibt 1. Sind beide Bits gleich, kommt 0 heraus.

Der Schlüssel ist ein Schalter. Steht im Schlüssel eine 1, wird das Bit umgekippt (0 → 1, 1 → 0). Steht eine 0, bleibt es, wie es ist. Genau das macht die Verschlüsselung.

Schritt 3 · Ein Buchstabe

H ⊕ K, Bit für Bit

Wir verschlüsseln den Buchstaben H mit dem Schlüsselbuchstaben K. Beide werden in Bits umgewandelt und dann Spalte für Spalte mit XOR verknüpft.

Das Ergebnis 00000011 ist die Zahl 3. In der ASCII-Tabelle ist 3 kein druckbares Zeichen, sondern ein Steuerzeichen. Darum schreibt man Geheimtexte meist als Zahlen, zum Beispiel hexadezimal: 03.

Schritt 4 · Ganzer Text

Ein Schlüsselwort, das sich wiederholt

Für einen ganzen Text schreibt man das Schlüsselwort so oft unter den Klartext, bis er abgedeckt ist – wie bei der Vigenère-Verschlüsselung. Dann wird jedes Zeichen mit dem Schlüsselzeichen darunter XOR-verknüpft. Klicke auf ein Zeichen, um die Bits zu sehen.

Bei HALLO WELT steht an Stelle 8 der Geheimtext 00: Dort trifft E auf den Schlüsselbuchstaben E. Gleiche Bits ergeben bei XOR immer 0. Und das Leerzeichen wird mit Y zum druckbaren y.

Probiere das Beispiel AAAAAAAAA: Der Geheimtext wiederholt das Muster 0A 04 18. Der Schlüssel schimmert durch.

Schritt 5 · Entschlüsseln

Zweimal XOR hebt sich auf

Das Besondere an XOR: Zum Entschlüsseln macht man genau dasselbe noch einmal. Wer ein Bit zweimal mit derselben 1 umkippt, ist wieder am Anfang. Eine 0 lässt es zweimal stehen.

(Klartext ⊕ Schlüssel) ⊕ Schlüssel = Klartext

Der Geheimtext kommt aus Schritt 4. Ändere den Schlüssel und schau, was passiert.
Geheimtext (aus Schritt 4)
Ergebnis

Wie sicher ist das?

Mit einem kurzen, sich wiederholenden Schlüssel nicht sehr: Wer ein Stück Klartext errät, rechnet Klartext ⊕ Geheimtext und erhält direkt den Schlüssel. Und die Wiederholung verrät die Schlüssellänge, wie beim Kasiski-Test.

Ist der Schlüssel aber zufällig, genauso lang wie die Nachricht und wird nur einmal verwendet, ist XOR beweisbar unknackbar. Das ist das One-Time-Pad. Auch moderne Verfahren wie AES verwenden XOR in jeder Runde.

Schritt 6 · Python

XOR in Python

Drei Bausteine genügen:

ord("H")

Zeichen → Zahl, hier 72

chr(72)

Zahl → Zeichen, hier H

72 ^ 75

XOR zweier Zahlen, hier 3

Ein Buchstabe

k = ord("H")                # 72
s = ord("K")                # 75
print(format(k, "08b"))     # Binärdarstellung mit 8 Stellen
print(format(s, "08b"))
print(format(k ^ s, "08b"))
print(k ^ s)
print(chr((k ^ s) ^ s))     # zurück zum Klartext
01001000 01001011 00000011 3 H

Ein ganzer Text

Mit i % len(schluessel) wiederholt sich der Schlüssel: Bei 3 Zeichen ergibt das 0, 1, 2, 0, 1, 2, …

klartext = "HALLO WELT"
schluessel = "KEY"

# Verschlüsseln
geheim = []
for i in range(len(klartext)):
    k = ord(klartext[i])                        # Buchstabe -> Zahl
    s = ord(schluessel[i % len(schluessel)])    # Schlüssel wiederholen
    geheim.append(k ^ s)                        # ^ ist XOR
print(geheim)

# Entschlüsseln: nochmals XOR mit demselben Schlüssel
text = ""
for i in range(len(geheim)):
    s = ord(schluessel[i % len(schluessel)])
    text = text + chr(geheim[i] ^ s)
print(text)
[3, 4, 21, 7, 10, 121, 28, 0, 21, 31] HALLO WELT

Der Geheimtext ist eine Liste von Zahlen und kein Text, weil viele XOR-Ergebnisse keine druckbaren Zeichen sind.
